# 💱 Futuristic 3D Currency Converter

An advanced, highly interactive currency converter with a futuristic 3D UI, real-time exchange rates, and glassmorphism design. Built with vanilla HTML, CSS, and JavaScript.

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Version](https://img.shields.io/badge/version-2.0.0-green.svg)

## ✨ Features

- **3D Tilt Interaction**: The converter card dynamically tilts based on your mouse movements for a truly immersive experience.
- **Glassmorphism UI**: A sleek, frosted-glass interface with neon glow effects and floating decorative elements.
- **Real-Time Rates**: Fetches the latest exchange rates using the [Currency-API](https://github.com/fawazahmed0/currency-api).
- **One-Click Swap**: Instantly flip 'From' and 'To' currencies with a smooth rotation animation.
- **Responsive Design**: Optimized for everything from mobile phones to large 4K displays.
- **Modern Typography**: Uses Plus Jakarta Sans and Outfit for a premium fintech feel.

1. Clone the repository:
   ```bash

   ```
2. Navigate to the project folder:
   ```bash
   cd Currency-convertor
   ```
3. Open `index.html` in your favorite browser.
